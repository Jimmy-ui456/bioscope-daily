# 生研观察产品优化顺序

微生物科研读者打开网站，是为了知道近期有哪些相关论文，决定先读哪几篇，并在需要时回到原文核对。评价改进时，先看能否减少漏读、误读和重复筛选，再看新增了多少入口。

| 优先级 | 读者任务 | 实施与验收 |
| --- | --- | --- |
| 已实施 | 看清文献库更新与新增记录 | 隔离定时任务测试的运行环境，核对补采和公开快照。研究雷达与收藏可按发表或首次发现日期筛选。较早发表、刚进入库的文献可在发现视图找到。 |
| 已实施 | 反复追踪同一个研究方向 | 研究雷达可命名保存、应用和删除本地搜索预设，覆盖查询、方向、标签和各项精细筛选。 |
| 已实施 | 判断是否值得精读 | 列表、详情与简报统一显示可读内容，并可筛出附可核对原文引文的未审核解读。文献类型和撤稿提示按来源标注。 |
| 已实施 | 续接上次的阅读 | 研究雷达和收藏支持手动标记与筛选阅读进度。已读状态按原文版本保存于本机。 |
| 下一步 | 核对版本变化和研究更正 | 优先接入来源明确给出的关联标识。用可核对的预印本与期刊版本样例验收，保留每个版本的原文、日期及来源。 |
| 已实施 | 把选中的论文交给组会或文献管理工具 | 公共日报与个人简报可导出本期 RIS。导出保留当期原始题录和版本标识。 |

已接入的原出版平台逐篇下载量继续按来源、文件类型和统计窗口独立展示。评估检索改进时，可以记录读者从打开页面到找到三篇相关论文所需时间，并人工核对选出的论文是否确实符合题目。
