# 生研观察产品优化顺序

微生物科研读者打开网站，是为了知道近期有哪些相关论文，决定先读哪几篇，并在需要时回到原文核对。评价改进时，先看能否减少漏读、误读和重复筛选，再看新增了多少入口。

| 优先级 | 读者任务 | 实施与验收 |
| --- | --- | --- |
| 已实施 | 看清文献库更新与新增记录 | 隔离定时任务测试的运行环境，核对补采和公开快照。研究雷达与收藏可按发表或首次发现日期筛选。较早发表、刚进入库的文献可在发现视图找到。 |
| 下一步 | 反复追踪同一个研究方向 | 支持保存和恢复筛选条件。先做本地保存，验证中英文查询、日期口径、期刊与文献类型均能恢复，旧收藏与备份仍可读取。 |
| 随后 | 判断是否值得精读 | 在列表和详情一致显示预印本、综述、摘要及译文可用性。研究解读维持原文可核对的引用，区分摘要证据、全文核验与人工校对。 |
| 随后 | 核对版本变化和研究更正 | 优先接入来源明确给出的关联标识。用可核对的预印本与期刊版本样例验收，保留每个版本的原文、日期及来源。 |
| 随后 | 把选中的论文交给组会或文献管理工具 | 在现有人工精选简报上增加结构化引文导出。先验证 DOI、题名与作者能正确导入，并能回到当时阅读的原文版本。 |

已接入的原出版平台逐篇下载量继续按来源、文件类型和统计窗口独立展示。评估检索改进时，可以记录读者从打开页面到找到三篇相关论文所需时间，并人工核对选出的论文是否确实符合题目。
