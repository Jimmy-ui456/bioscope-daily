# BioScope 阅读流程验收 · 2026-11-26

- 环境为公开的 GitHub Pages 网站，使用 Chromium 内置浏览器。修复前版本为 v0.2.48，修复后版本为 v0.2.49。验证了 1440 × 900 桌面和 390 × 844 手机视口。
- 使用 2026-11-26 13:06（北京时间）共享快照，共 397 篇，279 篇有中英对照。

| 顺序 | 操作 | 预期 | 实测 |
| --- | --- | --- | --- |
| 1. 检索 | 在研究雷达输入「代谢工程」和 `metabolic engineering` | 两种语言都能查到相关文献 | 分别返回 192 与 194 篇。新版桌面复测得到相同结果。 |
| 2. 查看详情 | 打开统一代谢视角综述，检查题名、摘要与「阅读原文」 | 中英内容对应同一篇，链接指向同一 DOI | 详情可见中英题名及双语摘要，链接指向 `10.1002/pei3.70225`，Crossref 以 DOI 查得同一题录。新版桌面复测对照和链接。 |
| 3. 收藏 | 从详情收藏，进入「我的收藏」并刷新。另从在线检索收藏同一 DOI 题录 | 收藏进入相应列表，刷新仍保留 | 基线版本的站内与在线收藏均通过刷新验证。新版桌面确认详情收藏进入列表。 |
| 4. 投票 | 在收藏对样本依次点喜欢、不喜欢、撤销，刷新后查看状态并比对推荐前八条 | 赞踩影响其他论文排序，刷新保留，撤销可恢复 | 基线桌面和手机尺寸均验证状态与刷新。桌面测试中，喜欢后前八有 3 篇新进入，改为不喜欢后有 5 篇从喜欢时的前八移出，撤销后恢复原排序。 |
| 5. 异常 | 用无匹配关键词检索，用 Europe PMC 提交两个关键词查询，打开仅有题录的 `PMC13751451` | 站内无结果、来源失败和缺摘要各有明确提示 | 基线两次 Europe PMC 查询在该浏览器超时，Crossref 精确 DOI 实查返回 1 条。仅题录记录明确标明阅读范围。新版确认站内无结果显示在线检索入口。用模拟响应通过超时、503、429、没有可显示题录、DOI 无匹配和成功返回的页面逻辑检查。 |
| 6. 尺寸 | 在桌面和 390 像素宽度检查列表、详情、导航及控件 | 内容无需整页横向滚动 | 基线在手机尺寸完成搜索、收藏与投票，研究雷达页面宽达 467 像素。新版同尺寸页面宽度测得 375 像素，已消除该处整页横向溢出。 |

## 修复与发布

- 窄屏网格列可随可用宽度收缩，横向标签区保持独立滚动。
- 站内关键词无结果时提供在线检索入口。在线来源失败、超时或无题录时提示当前来源，并提供切换入口。新来源使用当前可填写的字段，兼容的已输入值会保留。
- `npm test` 394 项通过，`npm run check` 通过。公开页面七项资源与修复提交一致。[部署记录](https://github.com/Jimmy-ui456/bioscope-daily/actions/runs/45840936133)

本轮抽查题录与摘要，全文和译文专业审校未纳入。浏览器控制连接间歇超时，新版真实来源的完整切换流程和收藏刷新、投票的完整回归未再次验收。手机以 Chromium 视口模拟，真机和第二浏览器未覆盖。
